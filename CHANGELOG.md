# VORTEX change history

This history summarizes the successive reconstructed portfolio iterations discussed and implemented during November 2026. The GitHub repository starts with the **V15 snapshot**; earlier versions are not represented as separate Git commits. Claims are based on prior QA summaries and are not independent production certification.

| Iteration | Key focus |
|---|---|
| V1 | Initial cinematic portfolio structure and sections |
| V2 | Scroll-linked transitions, sticky scenes, project motion |
| V3 | Richer project illustration and reduced unnecessary animation work |
| V4 | Freestanding portrait reconstruction and four project rows |
| V5 | Typography, spacing, responsive and dialog refinements |
| V6 | Dynamic fit of the large PORTFOLIO hero heading |
| V7 | Overflow fixes for all large headings, cards and footer |
| V8 | Centered footer name and mobile footer controls |
| V9 | Combined visual, interaction and accessibility finishing |
| V10 | Final baseline polish, keyboard and reduced-motion support |
| V11 | Optional light theme and persisted theme preference |
| V12 | Light-mode contrast and readability corrections |
| V13 | Modular/cacheable assets, adaptive motion, scroll optimizations |
| V14 | Faster scroll rendering and optional Netlify contact handler |
| V15 | Full-mode performance refinements, contact response validation, caching adjustments |

Current state: V15 staging candidate. See `docs/RELEASE_STATUS.md` for the unresolved acceptance requirements.
